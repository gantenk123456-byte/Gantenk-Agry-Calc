# Gantenk Agry Calc 🌾

**Gantenk Agry Calc** adalah aplikasi Micro-SaaS (berbasis web) utilitas agrikultur yang dirancang untuk membantu para petani menghitung dosis pestisida, mengkalkulasi kebutuhan penyemprotan berdasarkan luas lahan, serta mengidentifikasi penyakit tanaman secara terintegrasi. 

Aplikasi ini dibangun dengan semangat untuk menyediakan solusi yang **G**lobal, **A**daptif, **N**eoterik, **T**epat, **E**fisien, **N**yata, dan **K**olaboratif bagi sektor pertanian modern.

## 🚀 Fitur Utama

1. **Kalkulator Dosis & Tangki:** Menghitung presisi kebutuhan pestisida per tangki (dalam mililiter dan konversi tutup botol).
2. **Kalkulator Luas Lahan:** Estimasi total kebutuhan pestisida dan jumlah tangki yang diperlukan untuk area spesifik (m², Are, Hektar).
3. **Database Tanaman & Hama:** Filter otomatis pestisida yang relevan berdasarkan jenis tanaman dan target hama/penyakit.
4. **Integrasi Kamera Deteksi:** Dokumentasi langsung dari browser/perangkat *mobile* untuk merekam gejala fisik penyakit pada daun atau buah.
5. **Rekomendasi Solusi:** Panduan penanganan pertama untuk berbagai jenis penyakit umum pertanian.

## 🛠️ Teknologi yang Digunakan

* **HTML5** (Semantik dan penataan struktur)
* **CSS3** (Desain responsif dan modern UI/UX)
* **Vanilla JavaScript (ES6)** (Logika kalkulasi, DOM Manipulation, dan WebRTC API untuk kamera)
